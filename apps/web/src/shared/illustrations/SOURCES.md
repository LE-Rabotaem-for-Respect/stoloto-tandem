# Иллюстрации и пиктограммы: источники и лицензии

Все файлы в этой папке нарисованы командой проекта для этого прототипа.
Сторонние наборы иллюстраций и пиктограмм не используются, поэтому
чужих лицензий и требований об указании авторства у графики нет. Условия
использования — те же, что у остального кода проекта.

| Что                                           | Где                    | Формат                                             |
| --------------------------------------------- | ---------------------- | -------------------------------------------------- |
| Обложки 8 групп направлений (ТЗ 2.3, 2.11)    | `covers/*.svg`         | 320×180, цветные, без полупрозрачности             |
| Контурные обложки для темы «Высокий контраст» | `covers/outline/*.svg` | 320×180, только контур `currentColor`, без заливок |
| Пиктограммы статусов и действий               | `icons/*.svg`          | 24×24, контур 2 px цветом `currentColor`           |

Мотивы обложек совпадают с аксессуарами Хелфигочи по группам (ТЗ 5.4):
мяч — командные, кроссовки — выносливость, шахматный конь —
интеллектуальные, перчатка — единоборства, гантель и коврик — фитнес и
зарядка, очки для плавания — водные, лыжи — зимние, значок — другое.

## Как пользоваться

- Обложку выбирают по группе направления: `coverUrl(group, { contrast })`.
  Неизвестная или скрытая группа даёт обложку «Другое».
- Обложка в карточке — содержательное изображение: `alt` — название
  группы (`coverAlt(group)`). Пиктограмма рядом с подписью —
  декоративная, `alt=""`.
- Контурные обложки и пиктограммы рисуются цветом текста (`currentColor`),
  если SVG встроен в разметку. В `<img>` они чёрные; на тёмном фоне
  контрастной темы такой `<img>` инвертируют фильтром `invert(1)`.
